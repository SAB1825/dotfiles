# DankMaterialShell configuration

Snapshot of `~/.config/dms`, including shell settings, plugin settings, the
plugin lockfile, and generated Firefox styling.

The installed DankKDEConnect, DMS Profiles, Modern Clock, and Wallpaper Carousel
plugins are included with their source and bundled assets. DankKDEConnect's
local repository symlink is copied as a directory so this snapshot works
without the plugin manager's repository cache. Nested Git metadata, repository
caches, and first-launch/changelog markers are excluded.

To restore, back up your existing `~/.config/dms`, then copy this directory's
contents there. Adjust the wallpaper directory in `plugin_settings.json` for
your account and restart DMS. Copying this snapshot does not activate it or
change the running desktop configuration.
