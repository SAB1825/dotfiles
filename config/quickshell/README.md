This is a niri adaptation of the original Sway dots. It uses
[Ryu](https://github.com/Happilli/ryu)'s `phoenix` runtime, not `qs`.
The calendar uses English Gregorian month/day names and stores reminders by full
ISO date in the shell state, separately from the original Nepali calendar database.
The working tree is linked at `~/.config/quickshell/main`.

Run from a normal terminal inside your niri session:

```sh
bash ~/Rice/dotfiles/config/quickshell/scripts/setup.sh
```

The setup script updates Arch and installs `matugen`, `imagemagick`, `libnotify`,
`qt6-svg`, `ttf-cascadia-code-nerd`, `ttf-jetbrains-mono-nerd`, and `brightnessctl` using pacman, then installs
`wl-screenrec` from the AUR using yay. Normal pacman/yay review prompts remain.
Ryu, NetworkManager, PipeWire, WirePlumber, wl-clipboard, cliphist, UPower,
power-profiles-daemon, Polkit, PAM and nm-connection-editor are already installed
on this machine. Qt 6.12's qt6-base provides the Wayland platform plugin here.

Setup generates wallpaper colours and starts Phoenix in the terminal. Ctrl+C stops
the initial test. To start it again, run:

```sh
bash ~/.config/quickshell/main/scripts/start.sh
```

Niri's startup now calls this script. Until its dependencies are installed, the
startup script falls back to Waybar. When Phoenix starts, it stops Waybar, Mako
and swaybg so the shell can provide the bar, notifications and wallpaper.
The Refresh action is preserved exactly as requested; it runs `scripts/refresh.sh`,
including emptying Trash, clearing the listed caches and pruning temporary files.
It is never run by setup or startup.

| Shortcut | Action |
| --- | --- |
| Super+S | Shell settings, including wallpaper selection |
| Super+Shift+C | Clipboard history |
| Print | Region screenshot |
| Ctrl+Print | Full focused-screen screenshot |
| Super+Shift+Print | Lasso screenshot |
| Alt+Print | Native niri window screenshot |
| Super+Shift+R | Start/stop screen recording, without audio |
| Super+Alt+R | Previous column width preset |
| Super+Alt+L | Existing swaylock binding |
| Super+D | Existing fuzzel launcher |

Workspaces are dynamic and local to each monitor. The bar uses stable niri
workspace IDs, and shows running applications with click-to-focus/cycle.
Wi-Fi uses NetworkManager; it does not install iwd or change your network backend.
Enterprise Wi-Fi and advanced connection edits use nm-connection-editor.
Alacritty opens terminal applications, and Firefox opens the Monkeytype shortcut.

The bundled wallpaper and fallback palette make the shell usable without the
original author's images. Theme generation uses the private `theme/matugen.toml`
configuration and writes `~/.local/state/ryu/colors.json`; it does not replace
your general Matugen configuration. Choose images from `~/Pictures` in Settings.

Current limits:

- Window hover popups show clickable titles and an overview button instead of live
  thumbnails. Ryu's Sway window objects cannot be replaced with niri numeric IDs
  for capture. The custom sharing picker offers monitors only; browser/app window
  sharing continues to use the existing xdg-desktop-portal-gnome chooser.
- Screenshots, recording, night-light, brightness, audio, authentication and actual
  rendering still need verification in the real desktop session. They cannot be
  verified from the restricted tool environment. Screen recording requires a
  working encoder, normally VA-API.
- The GitHub tracker replaces Daily War. It shows `SAB1825`'s public profile
  contribution heatmap for the last year and up to 30 recent commits from today
  only. The graph includes other GitHub contributions such as issues and PRs;
  the separate commit count uses public default-branch commits by UTC authored
  date. The compact popup uses JetBrains Mono Nerd Font and larger text. Commit links
  open Firefox directly; the Open Profile button has been removed. No token is needed.
  The calendar is read from GitHub's public contributions page, whose HTML format
  can change; parsing failures are shown rather than rendered as empty activity.
  Refreshes every five minutes, with a 30-second minimum for manual refresh.
  Private/unpushed commits and non-default branches are absent from the commit log.
- The Monkeytype colour JSON is optional and is not generated by this adaptation.

Validation performed: all QML files parse, the niri configuration validates,
shell/Python syntax checks pass, fifteen adapter/tracker tests pass, and the shell plus a
widget fixture instantiate with the offscreen Qt backend. Live niri/D-Bus access
and root installation are blocked in the tool environment.

```sh
python -m unittest discover -s ~/Rice/dotfiles/config/quickshell/tests -v
niri validate
```
